Step 1: Deploy Backend to Render (15 min)
  1. Go to https://render.com
  2. New Web Service
  3. Connect GitHub
  4. Build: pip install -r requirements.txt
  5. Start: ./run_api.sh
  6. Get URL: https://roadsense-api-xxxx.onrender.com

Step 2: Deploy Frontend to Vercel (15 min)
  1. Go to https://vercel.com/new
  2. Import GitHub
  3. Root: frontend
  4. Env: NEXT_PUBLIC_API_URL_PROD=<backend-url>
  5. Deploy
  6. Get URL: https://roadsense-ai.vercel.app

Step 3: Test Live
  1. Open frontend URL
  2. Fill form
  3. Click Predict
  4. See results (should work instantly)
